# Форма управления учётными записями

Тестовое задание: форма учётных записей на **Vue 3**, **TypeScript**, **Pinia**, **Element Plus**.

## Стек

- Vue 3 + Composition API
- TypeScript
- Pinia (с сохранением в `localStorage`)
- Element Plus (UI)
- Vite

## Установка и запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Функциональность

- **Заголовок и кнопка «Добавить учётную запись»** — добавление новой пустой записи в конец списка.
- **Подсказка для поля «Метка»** — текст над/под полем и ограничение 50 символов, метки через `;`.
- **Список учётных записей** с полями:
  - **Метка** — необязательно, макс. 50 символов, ввод через `;`. В хранилище сохраняется как массив `[{ text: "элемент" }, ...]`.
  - **Тип записи** — выбор «LDAP» или «Локальная». При LDAP поле «Пароль» скрыто и сохраняется как `null`.
  - **Логин** — обязательно, макс. 100 символов.
  - **Пароль** — обязательно при типе «Локальная», макс. 100 символов.
- **Кнопка «Удалить»** — удаление учётной записи из списка и хранилища.
- **Валидация** по потере фокуса (текстовые поля) и при смене типа (селект). При ошибках — красная обводка; при успехе — сохранение/обновление в Pinia.
- **Сохранение** в Pinia с плагином `pinia-plugin-persistedstate`: данные переживают обновление страницы (`localStorage`).
